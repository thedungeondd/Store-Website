## 2. Training Objectives

By the end of training, users will be able to:

✅ Access the GitHub repository for the website  
✅ Locate and open the correct files to update contact information  
✅ Update store hours independently  
✅ Update phone numbers and address information  
✅ Save and publish changes to the live website  
✅ Access Instagram account for social media updates  
✅ Troubleshoot basic issues or know when to contact support

## 8. References

This training plan follows best practices in user-centered design and knowledge transfer for non-technical users, as outlined in:

*Redish, J. (2014). Letting Go of the Words: Writing Web Content that Works (2nd ed.). Morgan Kaufmann.*

- Clear, simple language
- Visual learning with screenshots
- Hands-on practice
- Ongoing support availability
